LIBRARY EXPLORER

A modern glassmorphism-style web app that lets users search millions of books using the Open Library API. It includes authentication, favorites, trending books, recent searches, AI-style login suggestions, and theme switching.

FEATURES

BOOK SEARCH
Search millions of books using the Open Library API
Fast live results with cover images, titles, and authors

TRENDING BOOKS
Automatically shows trending / popular books on load

FAVORITES SYSTEM
Add/remove books to favorites
Stored in localStorage (persistent data)
Instant UI update with counter

RECENTLY SEARCHES
Saves last searched keywords
Click to instantly search again
Stored locally (last 5 searches)

DARK / LIGHT MODE
Toggle between dark and light UI
Saved preference using localStorage

LOGIN SYSTEM
Simple login & register system (demo-based)
Create account functionality
Login state stored locally

AI LOGIN SUGGESTION
Suggests usernames while typing
Learns previously used usernames
Improves suggestions over time

BOOK DETAILS MODAL
Click a book to view details
Shows title and description
